# R0 仪器重构说明

上一版试点能跑通，但有几处会把「仪器缺陷」写成「研究发现」。本轮只修仪器，不改 `GOAL.md` 口径，不增删事件。

## 上一版的问题

1. **空分被算成 I 塌。** I1 几乎全是 `空`/`否`，模式「M 高 × I 塌」因此接近恒真。
2. **I1 从 M3 推导。** 事件层焦点唯一性泄漏进合约层发行权，两层不再独立。
3. **I5 用「收录了 10 个」当密度。** N=10 封顶让 I5 几乎总是高。
4. **DexScreener 结果未做同名过滤。** `pump` / `wen` / 别名 `夫妻` 会灌进无关代币。
5. **只保留最早 10 个再算粘住。** 赢家若不是最早，会被裁掉；粘住还用了全市场 24h 量，跨链稀释主场。
6. **E 层复制到每一个合约。** 那是观察者常数，不是币的属性。
7. **S2 从 category 自动填。** 近失被循环定义成「没有后排」。
8. **M 分写死在 Python 里。** 无 clock、无证据类，难以审计。

## 本轮改了什么

| 项 | 现在 |
|---|---|
| 同名过滤 | `src/common.py:term_matches`；短词要求 symbol/name 精确 |
| 别名 | 锁在 `events/aliases.csv`；`夫妻文学` 不再扩成「夫妻」；`pump` 改为 `pumpfun` |
| 全量克隆表 | `contracts_all.csv`（354）；打分仍只取最早 10（GOAL §2.2） |
| I1 | 仅用创建顺序：同链已有更早同名 → `否`；本链最早 → `空`（无指认日志不得打高） |
| I5 | 创建时及更早的同名条数，来自 all 表，不是 N=10 |
| I 塌 | **空 ≠ 塌**。`fragmented` = 同名≥3 且存在 I1=否 且无 I1=高 |
| 粘住 | 先在**主场链**上算 24h 量份额；clock=`collect`，不假装点时 |
| E / S2 | 只写事件级 |
| M | `events/m_scores.csv`，clock=`t0_narrative` |

未修（仍空，诚实）：I2/I3/I4、S1/S3、E3/E4、righttail、extract。Base CH / Sol 明文 name 仍缺。
