# 0 为什么测这一族

前两个收益轮（第 35 轮均值回归、第 36 轮做市）都撞在同一件事上：
**84 bps 的来回成本要求任何方向性预测挣出 85 bps 以上，而这个市场做不到。**

B1 的结构不同：**它不预测任何价格。** 两个池是独立的 AMM，各自被自己的单流推动，
没有任何机制强制它们同价，只有套利者交易才会拉平。价差是机械性存在的。
它也不需要做空，不需要借贷。

**这是当前唯一一个既不需要预测能力、又不需要借贷的策略族。**

反面风险要先写清：**这是最经典、最拥挤的策略**，机器人 24 小时在做。
价差很可能常年小于成本，或者在一个区块内就被吃掉。

# 1 数据与时间范围（本轮的硬约束）

**只用 `block_number >= 46000000`（2026-05-14 → 2026-08-17，95 天完整面板）。**

理由：一年期回填正在往 `census.cl_swaps` 写数据，中间区段不完整。
在不完整的时间序列上做本轮分析会产生虚假的价格跳变。
回填完成后可以重跑，但本轮不等它。

一个对本族有利的性质，先记下来因为它决定了度量的有效性：
**CLMM 池的价格只在有人交易时改变**（流动性增减不移动价格）。
所以"该池上一笔成交后的 `sqrt_price_x96`"**就是它当前的边际价格**，不是过期快照。
用前向填充构造价格序列在这里是**精确的**，不是近似。

# 2 宇宙（已冻结）

- 池必须有 R2 在 $5,000 档的**双向**实测成本（`buy_bps` 与 `sell_bps` 都有值）→ 537 个池
- 按 alt 代币分组，取组内所有**有序对** (A, B)：在 A 买入、在 B 卖出
- 得到 **86 个 alt / 726 个有序对**
- 主宇宙：**门槛 < 30 bps 的 52 个有序对**；同时分层报告 30–100 bps（92 对累计）

门槛定义（两条腿都含手续费与滑点，因为 R2 是对中间价的实测）：

```
hurdle_bps(A→B) = buy_bps(A) + sell_bps(B)
```

Base 上 gas 极低，忽略。

# 3 度量（已冻结）

同一 alt 的两个池，代币对相同，故 token0/token1 顺序一致（Uniswap 按地址排序），
价格 `p = token1/token0` 可直接比较，无需换算。

```
毛价差_bps(A→B) = 1e4 · (p_B − p_A) / p_A        # 在 A 便宜时才有意义
净_bps(A→B)     = 毛价差_bps − hurdle_bps(A→B)
```

# 4 决定生死的那个假设：我最快能在哪个区块成交

我不是 MEV 参与者，没有同区块能力。**观察到区块 b 的价差，最快在 b+1 成交。**

所以主判据不是"b 时刻的价差"，而是：

```
主指标 = 在 b 观察到 净_bps > 0 的条件下，b+1 时刻的 净_bps
```

同时报告 b+2、b+5、b+30（约 1 分钟）的衰减曲线。

**这是本轮唯一真正重要的数字。** 如果价差在 b+1 就消失，说明它已被机器人吃掉，
对我不可实现——即使它在 b 时刻真实存在。

**事前声明**：`b` 时刻的价差**不构成任何结论**，它只是信号定义。
任何"价差存在"的读数如果不带 b+1 的数字，都不得写进裁决。

# 5 裁决规则（先写死）

对主宇宙（门槛 < 30 bps）：

- **`ARB_EDGE_CONFIRMED`**：b+1 时刻条件净收益均值 > 0 **且**中位 > 0
  **且**按天分块 bootstrap 的均值置信下界 > 0（α = 0.05/52 对 = 0.000962）
  **且**事件数 ≥ 100 且分布在 ≥ 20 个不同日期
- **`ARB_CLOSED_BY_BOTS`**：b 时刻净收益 > 0 的事件存在（占比 > 0.1%），
  但 b+1 的条件均值 ≤ 0 —— 即价差真实存在但已被更快的参与者吃掉
- **`NO_ARB_SPREAD`**：b 时刻净收益 > 0 的桶占比 < 0.1%
- **`UNDERPOWERED`**：事件数 < 100 或集中在 < 20 个日期

任何裁决都不解锁 live。

# 6 事前记录的怀疑

1. **我预计裁决是 `ARB_CLOSED_BY_BOTS`。** 理由：跨池套利是链上最成熟的机器人业务，
   Base 上有专业团队做，且他们能在同一区块内原子完成，我不能。
2. **门槛最低的对（wstETH 2.0 bps、cbBTC 4.9、USDC 5.6、cbETH 6.7）恰好是
   竞争最激烈的对。** 便宜与可得可能互斥，这与第 36 轮"便宜与赚钱可能互斥"同构。
3. **R2 成本是单块实测**，用它算门槛有轻微前视泄漏。R3 的点时成本模型可用，
   但其 ±41% 误差在 2–7 bps 的门槛上是致命的相对误差，**所以本轮用 R2 实测值，
   并承认这个泄漏**。
4. **我的价差度量不含"我自己的交易会移动两个池"这一项。** 门槛里的 `buy_bps`/`sell_bps`
   已经是 $5,000 的实测滑点，所以这一项已计入。但如果多个套利者同时行动，实际更差。
5. **不含失败成本**：链上套利若第二条腿在我落块前被别人吃掉，我会持有一堆 alt
   并被迫以更差价格退出。本轮**不建模这个尾部**，因此结果偏乐观。
