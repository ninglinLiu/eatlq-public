# 3 宇宙：点时筛选，不许用未来信息

**不使用** 631 池或 71 池那种「活过 60 天」的集合——那本身就是生存偏差，
对做市尤其致命（在一个后来死掉的池里做市会亏光）。

每个进入日 d，宇宙定义为满足以下全部条件的池，**且这些条件只用 d 之前的数据**：

- 截至 d 已有 **≥30 天**成交历史
- **前 7 日**成交笔数 ≥ **500**
- 池有 WETH 腿
- 池在 R2 里有实测成本（否则成本不可知，剔除并计数）

**池在持有期内死掉不剔除**，按实际发生的结果计入。这是本轮避免生存偏差的关键。

# 4 价格区间（冻结，只用过去数据）

进入时价格 `p_d`，区间取对数对称：

```
[p_d · exp(-w),  p_d · exp(+w)]
w = c · sigma_7d · sqrt(24·T)
sigma_7d = 进入日前 7 天小时对数收益的标准差   # 只用 d 之前
```

- `c ∈ {0.5, 1.0, 2.0}` —— 窄 / 中 / 宽
- `T ∈ {1, 7, 30}` 天

共 **9** 个格子。Bonferroni 校正后 **α = 0.05 / 9 = 0.00556**。

区间宽度**只由进入日之前的波动率决定**。用未来价格路径选区间是这一族最经典的作弊方式，
本轮从定义上排除。

# 5 收益口径：必须对 HODL 作差

单独报 LP 收益会把资产自身的涨跌混进来。**唯一有意义的对照是「不做市，就拿着」。**

```
初始篮子   = 进入时为建仓所持有的 WETH 与 alt（按区间数学确定的比例）
HODL 价值  = 同一篮子在 T 天后按当时价格的价值
LP 价值    = T 天后仓位按当时价格的价值
净收益     = (LP 价值 + 手续费收入 - 进出成本) - HODL 价值
```

**净收益 = 手续费 − 无常损失 − 进出成本。** 全部以 WETH 计价，再换成名义的 bps。

# 6 进出成本（引用 R2 实测，不估）

建仓需要把手里的 WETH 换成区间数学要求的两资产比例，即一次单向 swap；
平仓需要把剩下的 alt 换回 WETH，又一次单向 swap。

- 成本率：该池 R2 实测的 **$5,000 档、两方向中较差者**（`cost_bps`）
- 建仓成本 = 需要换出的 alt 名义 × `cost_bps`
- 平仓成本 = 持有期末 alt 名义 × `cost_bps`
- **出区间的情形要按实际算**：价格若跑到区间之外，仓位变成 100% 单一资产，
  平仓时要换的量更大，成本更高。按实际持仓比例算，不用固定假设。

# 7 手续费计算（冻结口径）

对持有期内每一笔成交：

```
若该笔的 tick 落在我的区间内:
    L_mine  = 由 $5,000 名义与区间宽度按 CLMM 公式算出
    share   = L_mine / (L_active + L_mine)     # L_active 取该笔事件里的 liquidity 字段
    该笔手续费(以 WETH 计) = |WETH 腿金额| × fee_rate × share
```

三点必须说清：

1. `L_active` 是**我加入之前**的历史活跃流动性，所以分母加上 `L_mine` 才是我加入后的真实占比。
   不加会系统性高估收益。
2. 手续费只从**输入**代币收取。本轮统一以「该笔的 WETH 腿金额 × 费率」作为该笔手续费的
   WETH 计价值。理由：一笔 swap 两腿在成交时刻等值，无论费从哪一侧收，其 WETH 计价值一致（一阶）。
3. tick 在区间外的成交**不计费**，且此时仓位是 100% 单一资产。

# 8 本轮明确不建模的（会使结果偏乐观，必须在报告里写明）

- **我的流动性对价格冲击的反馈**：加入 $5,000 会让后续 swap 的滑点略小，
  从而略微改变成交量。名义相对池子流动性很小，视为二阶项。
- **其他 LP 的进出**：`L_active` 用历史实际值，已隐含真实的 LP 竞争，但不含
  「我进场后别人跟进」的反应。
- **Aerodrome 排放奖励**：Slipstream 的 LP 除手续费外还可能有 AERO 排放。
  **本轮不计**，因此对 Aerodrome 池的结果偏保守。
- **gas**：Base 上开平仓 gas 极低，忽略。

# 9 功效

$5,000 名义、T=7 天，则 94.6 天里每池约 13 个不重叠周期。
点时宇宙预计每日数十个池，故 T=7 时样本量在数百到数千。
T=30 时每池仅约 3 个不重叠周期，**功效最弱，可能只能给 `UNDERPOWERED`**。

p 值用**按天分块 bootstrap**（10,000 次），理由同前：同日跨池收益被市场共同因子相关。

# 10 裁决规则（先写死）

- **`LP_EDGE_CONFIRMED`**：净收益均值 > 0 **且**中位数 > 0 **且** p < 0.00556（Bonferroni）
- **`LOTTERY_DEPENDENT`**：均值 > 0 但中位数 ≤ 0，或去掉 |收益| 前 1% 后均值转负
- **`NO_LP_EDGE`**：均值 ≤ 0 且置信上界低于 0，且有功效
- **`UNDERPOWERED`**：置信区间覆盖 0 且宽度大于 |点估计| 的 2 倍

任何裁决都**不**解锁 live。

# 11 事前记录的怀疑

写在这里，以免事后自我说服：

1. 集中流动性做市在数学上是**卖出波动率**。若这段时间实现波动率高于费率隐含的水平，
   结果必然为负。这不是缺陷，是这一族的本质。
2. 第 22 轮的「均值正、中位负」很可能会重现——做市的收益分布天然左偏
   （小赚很多次，出区间时大亏一次）。**所以中位数是主判据，不是均值。**
3. 最便宜的池（wstETH、cbETH 1 bps）同时也是波动最低的池，费率也最低。
   便宜与赚钱可能是互斥的。
