# GL5v3 人话版

这次 archive 节点确实把最重要的一团雾拨开了。对象没有换：还是 2026-06-24 那份开着 F 防护的 644 选 120、每笔约 $50 的保守回测。它自己的旧成绩不是 +56%，而是月化 +8.57%；那个夸张的 +142.8% 是平均单笔回报，而且原来 120/120 都靠裸报价或 fork 模拟，不是真实钱包卖单。

现在能给一个很硬、但不是绝对零的答案：这 120 个 F-on 池没有一条被确认 rug；最快 +1 档的严格 rug 率已经从 `[0%,48.33%]` 压到 `[0%,2.50%]`，+5/+15 是 `[0%,0.83%]`。之所以不能写 0%，是独立审查指出：有 3/1/1 条虽然储备还在，但 target atomic 没成功，预注册要求它们继续未决，不能事后另设“只看储备就安全”的分支。另一方面，唯一一条 WETH 储备跌了 95% 以上的池，atomic roundtrip 和历史仓位 exact quote 都能卖，把它强记 −100% 也不诚实。证据因此强烈支持 F-on 把 pool-level rug 压得很低，并与激进版关 F 后吃进 207 个 rug 的方向一致，但没有证明精确为零。

收益问题也从“完全算不清”变成了“范围很窄、方向算清，但还不是一个点”。GL5v2 在最快 +1 档只能给 `[−36.1%,+143.7%]`；现在完整 120 笔的平均单笔回报界是 `[+136.7%,+147.7%]`。+5 是 `[+139.6%,+148.8%]`，+15 是 `[+147.7%,+149.0%]`。这些区间的最坏端都大于零，因此“这份保守版的利润大半是报价把 rug 洗白”不符合当前证据。和旧 +142.8% 比，+1 的诚实变化范围只是约 −6.1 到 +4.9 个百分点；+15 反而高 4.9 到 6.2 个百分点。

为什么还不给一个精确点？因为 +1/+5/+15 分别还剩 7/5/2 条缺满足事先规则的“历史仓位到底卖回多少 WETH”；其中多数已证明没 rug，另有 3/1/1 条连 rug 也仍未决。有的是冻结数据没有 entry BUY proxy，没法算出当时持有多少 token；有的是 target atomic 和 exact quote 只成功了一边；也有少量历史点 RPC 三次都没答。把这些腿按旧报价填满会过度乐观，全部按 −100% 又会过度悲观，所以继续保留双界。这不是收益方向未识别——三个下界都很高——而是预注册不允许把窄区间冒充点数。

同龄 644 baseline 也比以前清楚得多，但没有完全变成点估计。最快档 644 里确认 collapse 24 个、确认没 collapse 600 个、rug 仍未决 20 个；其 pool-level rug 率在 3.73%–6.83%。收益有 154 条未决，主要是原冻结材料根本没有 entry proxy，archive 不能替历史入场事实。即便用完整 population 的双界比较，F-on 相对 baseline 的条件 alpha 仍是正的：+1 至少 +86.5 个百分点，+5 至少 +93.9，+15 至少 +116.9。不能宣传成精确 alpha，但已经不是 GL5v2 那种只比几十条好子集的稀疏数字。

按结果方向，保守 F-on edge 是幸存，不是崩塌；但按事先写死的形式规则，只要还有一条收益 unresolved 就不能盖 `EDGE_SURVIVES`，所以机器状态仍是 `INCONCLUSIVE`。这个标签的实际含义是“强烈支持幸存、尚未满足零未决的形式门”，不是“双界还跨零”。右尾、去 top1、滚动窗口、bootstrap 与回撤门都通过，唯一失败项就是 unresolved 不等于零。

最后必须把边界说重：这轮证明的是池子层面、模拟地址在那个区块能卖，不是你的策略钱包必然能卖。token 可以按地址做黑名单、transfer hook 或限额；atomic 构造器不是策略钱包，也没有真实抢跑和 MEV。要补这个洞，需要钱包级历史证据或受控真钱验证，archive 储备本身补不了。全程没有碰真钱、没有签名广播、没有改 live、没有自判 GO；`GO=NOT_MADE`。
