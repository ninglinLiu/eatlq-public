# PIT「首次破线」后低买高卖（\$0.3M / \$0.5M）

## 规则（事先冻结）

- 宇宙：普查保守命中名单（\$0.3M→239；\$0.5M→123），去稳定币  
- **FDV 代理** = UniV3 WETH 池小时收盘价(USD) × **当前** `totalSupply`  
- **PIT**：只在「首次 FDV ≥ 阈值」的小时**之后**才允许交易  
- 策略：Z-score / RSI / 回撤抄底 / 均线 / 买入持有  
- 本金 \$1000、单笔 \$150、40bps+gas；时间 70/30 IS/OOS  
- 单笔收益截断在 ±100%（去掉脏 tick 爆炸）  
- `deploy_allowed=false`

## 样本现实（很重要）

| 阈值 | 名单 | UniV3 有曲线 | 破线后够长(≥80h)可测 | OOS 可评估 |
|---|---:|---:|---:|---:|
| \$0.3M | 239 | 239 | **11** | **10** |
| \$0.5M | 123 | 123 | **8** | **7** |

绝大多数币：要么清洗后 **算不出破线**（`NO_CROSS`），要么破线后 **历史太短**（`POST_TOO_SHORT`）。  
所以这不是「239 币大回测」，而是「破线后仍有足够 UniV3 小时线的一小撮」。

- **有微弱正线索**：破线后「从 168h 高点回撤 ≥10% 再买」在极小样本 OOS 上合计为正。
