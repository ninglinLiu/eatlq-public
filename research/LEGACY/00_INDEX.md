## 如果只读一件事

`02_METHOD_LESSONS.md`。

理由：150+ 个假设被杀，每个都很便宜，且**事后复核全部站得住**。
真正昂贵的是**六次度量事故**，每一次都用一个坏度量制造出假阳性，然后吃掉 1–3 轮。
所以杠杆不在「更快产生假设」，在**不允许一轮在仪器体检通过之前报出裁决**。

那份文件里最贵的一条：

> **任何以「表观收入」形式进入选择规则的量，都会被那个规则主动搜寻到它被高估的地方。
> 这类误差不会被平均稀释，而是被放大。**

具体代价：3,029 个池里只有 **1 个**费率快照高估（误差率 0.03%），
但选档规则精准地把 **42/47** 个仓位放进了那一个池——
**误差率 0.03% 的输入，产出了 100% 由该误差构成的结论。**

而最便宜的一条是 §7（2026-09-13 新增）：

> **「查不到」是最弱的证据，因为匹配逻辑里的任何 bug 都会产生它。
> 阴性结论必须配阳性对照，否则它对「数据真的缺失」和「查询写错了」
> 给出完全相同的输出——也就是不可证伪。**

它值得单独提，因为它是**在建这份索引的过程中当场犯下、当天查实、当天撤销的**。
我在已经写完前六条教训之后，仍然凭一个必然返回 0 的查询，往生产表写了 412,781 行冗余。
所以这条讲的不是「不知道要小心」，而是**「知道要小心也不够，因为验证工具本身可以是坏的」**。
它也是唯一一条**检查检查工具**的教训。

## 口径纪律（整个 LEGACY 目录通用）

这一节比任何单个数字都重要。本项目在下面每一条上都栽过。

1. **区分四种「没成」，它们的处理方式完全不同。**

   | 类 | 含义 | 该怎么办 |
   |---|---|---|
   | `FALSIFIED_IN_SCOPE` | **在明确写下的范围内**测出来了，答案是负的，且有功效 | 封死。除非换范围，别重开 |
   | `UNDERPOWERED_IN_SCOPE` | 排除不了，同时必须报出**最小可检测效应** | 不是证伪。要么加功效，要么正式注销 |
   | `INSTRUMENT_BLOCKED` | 数据/仪器缺失导致无法裁决 | **补仪器后重跑。这不是证伪** |
   | `NEVER_RUN` | 写了规格，零 PnL | 要么跑，要么正式注销 |

   另有一类要单独记：`MECHANISM_CONFIRMED_UNMONETIZED`——
   机制被确认为真、但绝对收益不成立。**这是正面发现，不是失败。**
   本项目有一个：费率档选择（配对 +69.5 bps，334 个独立块，ΔIL≈0）。

2. **任何裁决必须附适用域**，缺一项即不可引用：
   宇宙 / 时间窗 / 单笔规模 / 成本模型 / 标签语义 / 样本量 / **独立块数** / 对照基线。
   「独立块数」是最常被漏掉也最致命的一项——观测数 ≠ 信息量。

3. **不得把有限范围的结论外推成普适结论。**
   本项目最典型的一次：8 条「深度不够」的证据全部量自**新池**（0–2 天观测窗），
   读作「新池很浅」成立，读作「**Base** 很浅」不成立——差了 250 倍的池子数，
   以及一个占成交 64% 的场地。

4. **被推翻的结论保留原文并就地标注推翻来源，不要删除。**
   本项目多次因为「只留最新版」而丢掉了「为什么当时那样想」的线索。
   同一个深度问题上前后错了三次，正是这三次的对比才暴露出
   「度量少了一个维度，而缺失的维度恰好是成本藏身之处」这个模式。

5. **偏差的方向决定它是否推翻结论。**
   偏乐观的偏差 + 负结论 = 结论更硬。发现偏差先定方向，再决定要不要重跑。

6. **时变数字超过有效期必须重测。**
   一个池的收益率从 1,946 bps/周塌到 77 bps/周只花了两个月，
   而当时有一整份 GOAL 建立在那个过期值上。
