# 2 相对 R0 的三处改动，以及为什么

## 2.1 成本改用点时闭式模型（消除前视泄漏）

R0 用 R2 在**单一区块** 50123160 的原子实测值筛池，这对历史决策是未来信息，
且 2026 年前死掉的池根本没有成本值。

R1 改用 `census.pit_cost`（R3 仪器），每个决策日只用该日之前的数据：

```
cost_bps ≈ 1e4·fee_rate + 1e4·V/(L_med·sqrt(p))        # 前 7 日中位 L
feasible  = (前 30 日历史最大 WETH 取出量 ≥ 1.25 WETH)   # 单向陷阱闸门
```

**两者必须同时满足。** R3 已验证：分层一致率 93.6%、真便宜池 29/30 通过闸门、
陷阱池 0/4 通过。典型误差 ±41%。

**代价必须承认**：±41% 的成本误差会给净收益引入噪声，
而 R0 用的是实测值。所以 R1 的成本项精度**比 R0 差**，换来的是无前视且覆盖全历史。
两者结论若冲突，以此差异为首要怀疑对象。

## 2.2 宇宙不再受 R2 的 631 池限制（消除生存偏差）

R0 的成本只覆盖点时宇宙的 84.5%，缺失的是没活到进 631 集的池。
有了点时成本后，**任何有 WETH 腿且通过筛选的池都能进**，不论它后来是否存活。

## 2.3 持有期网格改为 {7, 30, 60}

R0 已用 64 个窗口把 1 天判死（均值 −8.3 bps，区间不含 0），不必重测。
新网格的独立窗口数（OOS 270 天）：

| T | OOS 独立窗口 | 全样本窗口 |
|---|---|---|
| 7 天 | 38 | 52 |
| **30 天（主）** | **9** | **12** |
| 60 天 | 4 | 6 |

60 天只有 4 个 OOS 窗口，**事前声明它大概率只能给 `UNDERPOWERED`**，
纳入网格仅为观察趋势方向，不指望它出裁决。

# 3 完全冻结的参数

与 R0 一致，不做任何调整（这一点是刻意的：改参数会让 OOS 检验失去意义）：

- 名义规模 **$5,000**，`ETH_USD = 4000`
- 区间 `[p·exp(−w), p·exp(+w)]`，`w = c·σ_7d·√(24T)`，`c ∈ {0.5, 1.0, 2.0}`
- `σ_7d` = 进入日前 7 天小时对数收益标准差，**只用进入日之前**
- 区间按 `tick_spacing` 取整
- 被动持有，**不再平衡**
- 点时宇宙：≥30 天历史、前 7 日 ≥500 笔成交、有 WETH 腿、`feasible = 1`
- 主宇宙成本层：`cost_bps_med < 30`；同时分层报告 30–100 与 100–300
- **模型有效性过滤**（R0 §4 引入，必须保留）：
  少于 1% 的在区间成交满足 `L_mine/L_active > 0.10`
- 手续费 `= |WETH 腿| × 费率 × L/(L_active+L)`，仅计 tick 在区间内的成交
- 基准 **HODL**：`净 = (LP 终值 + 费 − 进出成本) − 同一初始篮子 HODL 终值`
- 按天分块 bootstrap，20,000 次，Bonferroni **α = 0.05/9 = 0.00556**

网格 3 × 3 = **9 个格子**。

# 4 裁决规则（先写死）

对 **OOS** 段的每个格子：

- **`LP_EDGE_CONFIRMED`**：净均值 > 0 **且**中位 > 0 **且**均值置信下界 > 0
  **且**去掉 |收益| 前 1% 后均值仍 > 0
- **`LOTTERY_DEPENDENT`**：均值 > 0 但中位 ≤ 0，或截尾后转负
- **`NO_LP_EDGE`**：均值置信上界 < 0
- **`UNDERPOWERED`**：区间覆盖 0 且宽度 > 2×|点估计|
- **`UNTESTABLE_TOO_FEW_WINDOWS`**：独立窗口 < 5

**R0 的 30 天线索被认定为真，必须满足**：OOS T=30 至少一个 c 值拿到
`LP_EDGE_CONFIRMED`，**且**该格子的净均值点估计与 R0 的 IS 点估计**同号**。
否则记为 **`R0_HINT_WAS_NOISE`**。
