## 0 一句话

在 3 个费率档里选最好的那个，值 +69.5 bps，离零还差约 32。
本轮问：在约 50 个币里按「进场前 7 天、实测费率 × 成交/流动性」选最高档，
够不够补上。

**不够。** 最高档净 −61.8 [−158.6, +22.7]，两个半年都是负的。
相对当周中位符号：Δfee 只有 +13.8，ΔIL 却是 +146.4。
选高产出就是在买更活跃的币，无常损失先把手续费吃掉。

探索里那个 +122.7 用的是仓位**自己的已实现手续费**当信号。
换成本轮写死的池层面产出，高低档对调。预登记 §7.4 写过：二者若反向，
说明探索在拟合自己的 PnL。现予撤回。

## 3 探索 +122 为什么是假线索

| | 探索（不得确认） | 本轮确认信号 |
|---|---|---|
| 排名用的量 | 上一窗**本仓位**实现手续费 | 进场前 7 天**池**产出（实测费率） |
| 最高档净 | +122.7 [+27, +211] | **−61.8 [−159, +23]** |
| Δfee / ΔIL vs 当周中位 | +438 / +340 | **+14 / +146** |
| 独立留一 | 前 8 名单删仍过零 | 无需，本身不过零 |

同一批仓位、同一个 T=7 / c=0.5 / $50 / 实测费率面板。
只换了「谁进最高档」的规则，符号就反过来。
**+122 是「上周赚了手续费的仓位下周还赚」的自相关，不是可交易的横截面。**

## 4 对 32 bps 差口的含义

C2 选档：不选 −110.8 → 选档 −31.9，增益 +69.5，配对设计下 ΔIL≈0。
跨币种选仓：增益不存在，ΔIL 远大于 Δfee。

差口补不上。做市这一族现在是：

- C1 不选档：确认亏损
- C2 选档：机制真，绝对收益仍跨零（−32）
- C3 慢交叉：证伪，cbBTC 线索撤回
- 跨币种按产出轮动：用写定信号后点估计为负，探索正收益作废

**在费率档之外再挑币，至少用这个信号，补不上那 32 bps。**
