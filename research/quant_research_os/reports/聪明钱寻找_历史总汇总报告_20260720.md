## 0. 一句话总裁决

**没有任何一条「识别单个聪明钱钱包 → 延迟跟单/狙击」路径，被认证为可投真钱的 edge。**

- **RH/CHA**：在「真实下一笔成交」口径下，跟单/共识主线被证伪（先前漂亮成绩主要是成交幻觉）。
- **Base/EATLQ**：早期多轮 sprint 已判 `REJECT_NOT_COPYABLE` / `WONTFIX`；后续 RH 方法复现因**归因与资格地基**不足，merit 停在 `UNTESTED`（不是测出没 edge，是没资格测）。
- **唯一反复存活的是方法资产**：归因护栏、point-in-time 名单、去集中、延迟税、真实成交、右尾判据，以及「多钱包共识 / 池级结构」去噪思路——不是某个可部署的聪明钱名单。

Live 主线早已不是跟单，而是 **KEYSTONE 左尾过滤**（筛灾难，碰偶发右尾）。

## 4. 线 B · EATLQ / Base：从「找聪明钱」到 WONTFIX

### 4.1 总体定位（2026-07 家底调研）

- Live 主线 = **新池狙击 + 左尾 ML（KEYSTONE）**  
- **不是**跟单聪明钱  
- `services/strategy` 里 smart-money 分支代码仍可能残留，但审计已判 `REJECT_NOT_COPYABLE` / **WONTFIX**（约 12 sprint 失败史）  
- 公开失败原因之一：holdout PF≈0.08、latency 吃 edge  
- 结构矛盾：小资金 vs 白皮书假设（onset 候选/全网 smart money 样本数量级远低于叙事）

### 4.2 方法族一：sender-gated / wallet-profile（终局 DEAD）

**目标：** 用 sender/钱包标签做 onset 闸门或跟单输入。

**关键尝试：**

| 方法 | 做了什么 | 结果 |
|---|---|---|
| smart_money 二进制 gate | 标签命中才进场 | null 检验：random gate 的 PF 远高于 real → `gate_likely_spurious` |
| v1 / v2 dual-metric null | PF>1.5 且 n≥15 且 real>null p95 | 全部 REJECT 或 INCONCLUSIVE |
| strict PIT 标签 | 更严的 PIT 聪明钱集合 | 集合过小（曾仅 7 个 sender），功效不足 |
| 衰减审查 | 7d/14d vs 21d+ | PF>1.5 只在短窗；长窗衰减；像短命 regime 非稳定 cohort alpha |

**终判文档要点（`FINAL_VERDICT.md`，2026-05-24）：**

- Branch：**DEAD — pivot to pool-centric onset + 4-dim fusion**  
- 不得把 sender-gated 升为 supersede candidate  
- 教训：脏基建上调标签 = 过拟合；`sender` 语义必须是 `tx_from`，否则 router/WETH 污染  

**推荐 pivot（当时）：**

1. 池级 onset / 热度簇，去掉对二进制 smart_money 的依赖  
2. 白皮书 4 维融合，钱包标签最多当弱先验  
3. cluster gate（≥2 不同买家）当**池信号**，不当钱包标签  

### 4.3 方法族二：Sprint094 聪明钱预检 / 画像

**发现（非常重要的「画像否定」）：**

1. 候选钱包 14d 中位 buys 可达数百～上千，对照仅个位数 → 强 selection：来源是**高频复购**，不是「真聪明钱」。  
2. `smart_money_score` 在候选/对照上都接近 0，区分度弱。  
3. CH-only 画像**没有出现**明显聪明钱 cluster；最强信号像 early sniper，但样本小。  
4. winner vs near_miss 的 case-control：画像几乎相同，差别更像短窗随机走势 → **winner-only 聪明钱假设被驳回**。  
5. Base alt-pool「赢家」主体更像**抢跑后立刻 dump 的 scalper**，不是 sniper-and-hold。  
6. 历史失败裂隙反复命中：`SINGLE_TOKEN_CONCENTRATION`、`SAMPLE_TOO_SMALL`、`DIRTY_LABEL` 等。

**结论：** 过滤高频/MEV 后剩少量「更像持有者」的候选，但 token 集中、样本薄，**从未形成稳定可复制聪明钱集合**。

### 4.4 方法族三：P3 预测力 vs P3A 执行 EV（关键转折）

#### P3（2026-06-13）——「唯一做到的 OOS 预测信号」

- 训练段构建聪明钱集 S（剔除碰死亡池的无差别 bot）  
- 应用到 OOS 新池：各档 lift **2.6×～11.3×**  
- 解读：  
  - 预测力穿越样本外（相对当时其他失败线）  
  - 但是**部分信号**：最多抓约 27% 赢家；被买池仅约 10% 是赢家  
  - 精度/召回权衡尖锐：严 S → 高 lift 但 n 太小  

当时建议方向：别广撒，**只在聪明钱触达的池上集中下注**。

#### P3A（紧接着）——集中下注不能变成钱

| 子集 | n | EV | PF | 解读 |
|---|---:|---:|---:|---|
| 全 OOS 广撒 | 301 | −0.49 | 0.18 | 基线死 |
| SM min_win1 | 20–27 | −0.43～−0.48 | 0.18–0.24 | 统计有效格牢负 |
| SM min_win2 dt0 | 4 | +0.32 | 1.90 | n=4 噪音，不可信 |

**统一诊断：**

> P3 lift 预测的是 **mfe_72h≥5x（纸面峰值）**；纸面峰值在薄池兑不了现。  
> 「聪明钱能预测纸面暴涨」可以为真，但经济上无用。

**第一性原理结论（当时）：**

- 零售仓位 + Base 土狗薄池右尾猎杀，**不是 +EV 游戏**——执行/流动性墙锁死  
- 不再推荐为这条路做全量 tx_from 回填「把名单做更大」——只会更准地预测一个抽不出来的目标

### 4.6 Base 上「跟单」为什么特别难（市场结构）

即使不谈 PnL，身份层就先塌：

1. **`tx_from` 全史覆盖极低（约 0.65%）**——大量交易走智能钱包/账户抽象，`tx_from` 是 bundler/EntryPoint。  
2. **净流向/收币方归因虚高**——一度覆盖看起来很高，挤水后大量落在合约钱包；头部包括共享合约、协议金库（曾把 Balancer Vault 当成「聪明钱受益人」；某地址 199 个不同签名者打进同一处）。  
3. **中转稀释**——即便落在 EOA，大量买入币流向归集/中转地址，不是决策者本人。  

指挥简报原话大意：

> 「识别单个聪明钱→跟单/狙击」在 Base 上**先天缺地基**，不是调参能救。限制的是一整类策略。

建议优先级：

1. **转不依赖钱包身份的池/代币结构信号**（推荐）  
2. 只做干净 EOA 少数派下限证据（明确有偏）  
3. 深水区 call-trace / solver 内归因（工程大、性价比差）

## 5. 线 C · RH/CHA：最完整的「找聪明钱」证伪实验链

主合集：`/root/rh链聪明钱0714.md`（2026-07-14）

### 5.1 研究问题

> 这条链到底有没有可识别的常胜聪明钱？换成技术选择器/共识后，是否跨窗 persist？真实成交后是否还活？

### 5.2 统一裁决口径（右尾适配，重要）

土狗是右尾市场，「中位数 > 0」是错误的传统量化判据。预注册右尾 persist 大致要求同时满足：

1. **正期望持久**：pooled 均值净 > 0；坏窗不能深亏（如坏窗均值 ≥ −5%）  
2. **不爆仓**：真实时间顺序 equity 最大回撤可承受；小仓位无 ruin  
3. **尾巴可捕获**：正收益不能全靠 top 1% 单子；剔尾后仍要讲得通  
4. **调度下行地板**（修订后）：蒙特卡洛终值 p5 显著为正、最深回撤 p95 可承受——回答「是不是靠调度运气抽签」  

禁止：用切点后数据选钱包；看结果回调参；用打散平均回撤冒充序列回撤。

### 5.3 数据地基：Router 误归因（先破案再谈名单）

**悬案：** 某些「聪明钱」看起来几乎零卖出。  

**破案：** 不是模型幻觉，是 `swaps.wallet` 被 Universal Router 等误归因。  

**教训写入资产：**

- 「没有卖出」类断言必须先排除归因 bug  
- 分析层要用 resolved EOA 口径，不能直接信 router 坍缩后的 wallet 字段  
- 实盘跟单与回测必须同一归因，否则验证的不是会跑的系统  

### 5.4 三代「聪明钱名单」（勿混）

| 代际 | 做法 | 可信度 |
|---|---|---|
| 手动监控 | 关系户/传闻地址 | 轶事，非 OOS |
| 旧 v2（~2026-07-09） | 基于有误归因的 `swaps.wallet` | **污染**，勿再用 |
| CHA 新方法（2026-07-13） | resolved 归因 + 反 MM（卖买比） | 可用于研究，仍非实盘认证 |

**反 MM：** 用 `max_sell_buy_ratio`（如 4× / 更严 2×）过滤做市型「两边都做」的地址；边界盘仍可能漏进。

### 5.5 OOS 延迟跟单的早期读数（触发后续选择器研究）

典型形态（CHA OOS，$50/笔，滑点/gas 计入）：

- 跟单**均值**可以显著高于随机早买基线（右尾把均值抬起来）  
- **中位数全程为负**  
- 盈利靠少数大赢家  
- 旧 v2 OOS 曾为负；CHA 改善后均值好看，但**不足以直接上实盘**  

#10 walk-forward 进一步证伪：按**绝对已实现 PnL** 选 top-30 + 固定/止盈出场，**跨窗不 persist**。  
触发假设：失败主因可能是**选择器选运气**，不是单纯出场规则。

### 5.6 TASK 1：技术型单钱包选择器电池

可插拔选择器（切点前数据 → 钱包列表）：

| 选择器 | 逻辑 |
|---|---|
| `abs_pnl` | 绝对已实现 PnL（坏基线） |
| `winrate` | 胜率，`n_closed` 门槛 |
| `median_pnl` | 中位 closed PnL（抗单笔离群） |
| `deconcentrated` | `top1_realized_share < 0.5` 后再按 PnL |
| `risk_adjusted` | PnL / 波动或回撤 |

**结论：5/5 均不跨窗 persist。**  
技术型单钱包选择器在本链此周期站不住。

### 5.7 TASK 1.5：右尾重判

动机：单钱包利润极度尾部集中；并发槽位少时，赚不赚取决于「暴涨时槽里有没有它」的调度运气。

对 deconcentrated 等做：

- 真实时间序列回撤（非打散平均）  
- top1%/5%/10% 尾部贡献  
- 固定小仓位 + 并发上限破产检验  

阶段结论大意：在本任务三项判据内，deconcentrated **未被证伪为纯 top-1% 幸存者**（TP 组合相对更好），但**还不能升级为执行级真 edge**（缺真实容量/sell-sim 等）。

### 5.8 TASK 2 / 2.5：共识信号（从「跟钱包」变为「跟抱团」）

**信号定义：**  
同一 token 在滚动窗（如 30min）内，被 ≥N 个不同 smart-ish 钱包买入才跟（N∈{2,3,4,5}）。  
smart-ish 池用切点前 deconcentrated top-30/50/100。

附加硬要求：

- 盯市（MTM）回撤与 realized 回撤并列  
- 调度蒙特卡洛（并发槽位随机到达）量化「靠运气」方差  

**阶段性「最强候选」（触发价/乐观成交假设下，2026-07-14 曾认定）：**

- `P100_N5_30m + trailing` / `P100_N4_30m + trailing`  
- 四窗全正、尾部集中度下降、MC 下行地板好看  

这是研究过程中**纸面上最强**的跟单形态——也正因如此，后面必须过真实成交门。

### 5.9 TASK 3：真前向 + 容量 + trailing 成交真实性（候选基本证伪）

关键一刀：

> trailing/止损出场若按「触发价」成交，物理上常做不到（卖在下跌，薄池填不到价）。  
> 改为「触发后下一笔真实成交价」后：全样本均值大约低 **~207pp**，中位低 **~135pp**，八成以上单子更差。  
> 把折扣套回原先 +187% 一类均值 → **均值/中位可转负**。

结论：**候选 edge 的漂亮成绩是成交幻觉 artifact。**  
容量代理亦不足以支撑外推；短前向窗样本不足。

### 5.10 TASK 4：真实成交全历史 walk-forward（决定性）

对 fixed / tp50 / trailing / **tp_ladder(+30/+60/+120)** × 单钱包与 P100_N4/N5，全部用真实下一笔成交重算。

**明确裁决：**

- **没有任何信号×出场组合在真实成交下同时跨窗正期望并通过四判据。**  
- **之前 edge 是成交幻觉。**  
- 跟单线降级观察；不投钱；不自判 GO。  

**仍捞回两条可长期沿用的设计原则（不是已认证 edge）：**

1. **出场必须限价卖在强势（阶梯）**；禁 trailing / 市价止损当主出场  
2. **多钱包共识（P100_N4 一类）是好去噪入场器**  

**元瓶颈：** 所有实验压在约 7/10–7/13 单一时代，已被榨干；再刷 backtest = 对该时代过拟合。新证据维度主要是**时间前进的前向观察**。

### 5.11 TASK 5–6：前向观察与过滤扫描

- TASK5：P100_N4 纯前向只记录观察器（不下单），冻结钱包与水位线，镜像 live 闸门只记录。  
- TASK6：在真实成交口径上扫年龄/流动性/命中率/仓位等过滤——可找到「本时代内」多组四判据全过的组合，但报告明确：**同一短时代内筛选有选择偏差，不能认证或自判 GO**。最干净前向假设方向偏向「共识 × token 年龄≤2h」一类。

### 5.12 TASK 7：跳出单钱包跟单的新信号源

在同一真实成交 + tp_ladder 框架下探索：

- 早期流动性/活跃门槛  
- 结构：成交额增速、holder 增速、买卖笔数比、combined  
- 聪明钱首买排名 k  

**同时代四判据全过的非跟单候选（研究级）：**

- `structure_T2_liqgrow2`  
- `structure_T2_holdergrow2`  
- `structure_T2_liqgrow4`  
- `structure_T2_combined`  
- `structure_T5_liqgrow2`  

去相关审计后，真正有 exclusive key 的独立信号更少（约 3 个）；并集重跑四判据仍过，但**仍是同短时代研究重跑，不是前向认证**。

**聪明钱首买 `smart_first_k*`：** 有些均值尚可，但四判据未全过，不能当救命稻草。

### 5.13 RH/CHA 实盘前 10 件事（方法论清单，仍有价值）

## 6. 线 D · Base 复现 RH：RH1 / B2 / GL2-B

### 6.1 RH1（2026-07-14）：方法复现，merit 未测成

目标：在 Base/EATLQ 上复现 RH 的 PIT 聪明钱选择、延迟跟买、真实成交退出；吸收 RH router 误归因与成交幻觉教训。

**冻结护栏（摘要）：**

- 不用 `swap.sender` 当钱包（B1 已证 sender 把大量身份压进 router）  
- 主口径仅高覆盖窗内 `tx_from`  
- 切点前已闭合 episode 排名；切点后只验  
- 五选择器电池  
- 延迟后第一笔真实成交入场；阶梯限价出场；无容量不删样本  

**高置信短窗资格结果（核心数字）：**

| 条件 | 钱包数 |
|---|---:|
| 已闭合 episode ≥2 | 105 |
| 其中 realized PnL > 0 | 35 |
| 再要求 top1 正利润占比 < 50% | **0** |
| 再要求 sell/buy ≤2 | **0** |

因此 RH 主选择器 `deconcentrated top-30` **没有名单** →  
`INCONCLUSIVE_NO_ELIGIBLE_WALLETS`（不是收益 FAIL）。

探索臂里有成交的选择器方向为负，但 n=1～4，按预注册只能描述，**不能称 powered FAIL**。

**审查纠偏（RH1_review）：**

- 真正 headline 不是「聪明钱跟单已被证伪」，而是：**Base 上大量交易者是智能钱包，tx_from 口径系统性漏掉他们**；短窗使去集中门机械失败。  
- 维持：`CANONICAL_MERIT = UNTESTED`，`GO = false`。

### 6.2 B2 transfer-net：覆盖率救援证伪

为把覆盖率救到 >90% 做 token 净流向反向归因，经多轮审查 + 链上 golden：

- 表面覆盖可被做高，但挤水后大量落在合约/共享金库  
- 剔除已识别共享合约后，能干净归到单个交易者的 swap **约仅 47.8%，且仍不干净**  
- EOA 自证等硬门失败 → RH1 **不得**改用 B2 扩样本  

### 6.3 GL2-B（2026-07-15）：工程门过，资格污染

- EOA `resolved == tx.from`、trace golden、FIFO `balanceOf` 整数对账等**限定工程门通过**  
- 但冻结资格阈值机械选出的钱包中，有 oversell（观察窗前已有库存）→ **FIFO PnL 左截断污染**  
- 完整库存的合格钱包在前向窗**没有买入信号**；前向 4 条信号全部来自污染钱包  
- 这 4 笔负回报**不能**证明有 edge，也**不能**证明没 edge  
- 终局：`UNTESTED_ELIGIBILITY_CONTAMINATED`  
- Nansen 等外部标签：无授权则 `NOT_RUN`，不得伪造

## 9. 跨项目反复验证的教训（真正值钱的部分）

### 9.1 归因先于名单

Router / Universal Router / bundler / 共享合约会制造：

- 「零卖出」假案  
- 「协议金库是聪明钱」假案  
- 回测与实盘跟的不是同一群人  

**没有干净身份，就没有聪明钱策略——只有噪声标签。**

### 9.2 Point-in-time，反幸存者

钱包资格只能用决策点之前已闭合的真实盈亏/行为；  
用「后来变有钱」的地址 = 事后诸葛。

### 9.3 去集中是硬门

利润靠单笔暴击的「历史赢家」不是可跟技能。  
窗口太短时，`top1_profit_share` 会**机械趋近 1**，去集中门会「无论质量如何都过不了」——这是窗长问题，不要误读成「Base 没有赢家」。

### 9.4 右尾市场要用右尾判据

均值好看 + 中位为负 = 典型土狗；  
「中位数>0」当主门会系统错杀或误导。

### 9.5 成交真实性 > 纸面曲线

- 卖在弱势（trailing/止损）在薄池经常填不到触发价  
- 限价卖在强势才有物理意义  
- 必须并列报：聪明钱本人收益 / 延迟跟买收益 / **延迟税**  

### 9.6 纸面峰值 ≠ 可捕获 EV

P3/P3A 是最干净的反例：预测力可以真，零售仓位仍可以永久 −EV。

### 9.7 延迟与容量是一等公民

分钟级 ingest/执行滞后时，「看见他买再跟」的 edge 常被吃光；  
容量不建模的正期望是玩具。

### 9.8 样本不够就写 UNTESTED

禁止把 n=0、n=4、资格污染、覆盖不足包装成「聪明钱没 edge」或「已证伪」。  
诚实标签本身就是资产。

### 9.9 代码残留 ≠ 策略存活

EATLQ 仓库里仍可能有 smart_money 计数分支；策略层裁决以审计/WONTFIX 为准。
