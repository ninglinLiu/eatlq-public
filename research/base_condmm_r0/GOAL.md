## 1 经济论证（为什么这条与 C2 不是同一件事）

单个做市仓位的净收益：

```
net ≈ 手续费收入 − 无常损失 − 执行成本
手续费收入 ∝ 成交量 × 费率 × 我的流动性份额
无常损失   ∝ 已实现方差（集中仓位按 1/宽度 放大）
```

所以 net 的符号由 **（成交量 × 费率）/ 方差** 支配。

**C2 选的是 `yield = Σ 费率×|额| / L_active`——分母是活跃流动性，不是方差。**
它只优化了收入项。第 40 轮 Test B 的实测与此吻合：选档把 Δ手续费拉到
+20.8 ~ +139.2 bps 而 **Δ无常损失 ≈ 0**（−6.7 ~ +0.2）。
即 C2 成功地在**不改变 IL 的前提下**提高了费收入，然后**绝对值仍然亏**——
说明 IL 的**水平**本来就高于费。

**C2 抬的是分子。C1b 要抬的是比值。** 这是一条机制上不同的假设，
不是 C2 的参数变体。若 C1b 成立而 C2 不成立，差别应当出现在 IL 项而不是费项。

## 3 预测量（全部点时，只用进场日之前的 bar）

对每个（池 p，进场日 d），回看窗 L 小时，取 `bar < d` 的 bar：

- 小时对数收益 `r_t = ln(close_t / close_{t-1})`
- **稳健波动** `sigma_rob = 1.4826 × median(|r_t − median(r)|)`（MAD 估计）
- 每小时费收入代理 `Rbar = Σ(vol_weth_t × 费率) / L`

四个预测量：

| 代号 | 定义 | 方向 | 角色 |
|---|---|---|---|
| **P2** | `FV = Rbar / sigma_rob²` | 取**高**分位 | **主预测量**（理论正确的选择变量） |
| P1 | 同 (池,T,c) 上一个不重叠仓位的已实现 `net_strict_bps` | 取**高**分位 | 次要（「LP 盈利是否有持续性」，零建模） |
| P3 | `sigma_rob` | 取**低**分位 | 对照（朴素「安静」预测量） |
| P4 | `Rbar` | 取**高**分位 | **反向对照**（C2 式纯收入变量。若本轮论证成立，P4 应当**不**work） |

**为什么用 MAD 而不是过滤坏点**：第 41 轮方法债第 1 条记录，
在深宇宙上预登记的 `MAX_ABS_LR = 2.3` 搬到 $50 宇宙后有 10.8% 的 bar 超标，
「中和它们可能是在丢信号而不是丢噪声」。MAD 对尾部不敏感而**不丢弃任何 bar**，
从构造上绕开这笔债。**本轮不使用任何收益幅度过滤器。**

**唯一允许的剔除是 CLMM 刻度极限**（第 40 轮强制条款 3）：
若 `p_entry` 或 `p_out` 非有限、≤0、或落在 `1e-30` 以下 / `1e30` 以上，该行剔除。
这是一个**报价有效性**判据，不是收益幅度判据（第 40 轮实测坏点为 `1.0001^-887272 ≈ 2.9e-39`，
与真实行情分离得很干净）。剔除行数必须在报告里报出。

**回看窗** L ∈ {24, 168, 720} 小时。**主检验固定 L = 168。**

## 6 机制侧的事前定量预测（本轮可以在机制上被证伪）

从 §0 的赔付表和 T=7 的基准状态频率（静 25.1% / 涨 41.1% / 跌 33.8%，n = 24,803）
可以算出打平所需的状态频率。设涨跌维持 0.548 : 0.452 的原比例：

```
80.8·x − (109.1×0.548 + 164.6×0.452)·(1−x) = 0  →  x = 0.624
```

**事前预测：主检验若要过零，被选中子集的「静」占比必须约 ≥ 62%（基准 25.1%）。**
T=30 的同一算术给出 **43.4%**（基准 12.5%）。

这两个数字提供一条独立的机制检验：
- 若净收益过零而「静」占比**没有**升到 ~62%，说明收益来自费项而非 IL 项，
  与 §1 的论证不符，必须在报告里明确指出并降级为「机制未确认」。
- 若「静」占比显著上升而净收益仍不过零，则 IL 侧机制成立而幅度不足，
  这是一个**有信息的部分结果**，应当报出而不是记成全败。
