## 5. 重要 Caveats

1. **median ret = −3.0% 几乎每天相同**  
   在 3,439 条有定价 ret 中，**1,534 条（45%）恰好 = −3%**（≈ 纯成本、T+15≈T+90 价）。稀疏 snapshot 对右尾 **严重欠定价**，不能用于 mega 通道验收。

2. **API hit vs 链上 ret 脱节**  
   hit100 API ~4%，链上 ret≥100% 仅 0.26% → 应用 **API 看 universe 右尾频率，链上 replay 看可交易性**。

3. **16 天空样本**  
   05-17~06-01 需补 enum 才有完整 30d；当前结论 **仅限 06-02~06-15**。

4. **成本**  
   已统计 **1.31M credits**（~$0 超额 on Build）。
