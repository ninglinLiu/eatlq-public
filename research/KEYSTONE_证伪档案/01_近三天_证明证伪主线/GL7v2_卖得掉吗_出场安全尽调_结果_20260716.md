# GL7v2 · "卖得出去吗"交易前出场安全尽调（结果）

## ⚠ 两个必须先读的限制

1. **本轮由审查 Agent 亲自设计 + 执行（人类一次性授权破例），因此缺少平时的独立第二方复审。** 结论未经第二个 agent 交叉核验；下面结果应按"单方执行、自证"看待，权重低于有独立复审的 GL1–GL5v3。
2. **archive RPC 有跑间边际抖动**：哪几个只读调用偶发超时/重试每次不同，导致 evaluable 计数 ±数条、RPC ledger 行数不同。**实质裁定对此稳健**（确认失败、确认坍塌、207 校准均为确定性），只有边际计数会浮动。

## 0. 一句话结果

对保守 F-on 120 选中集做四条独立、只读的"卖不卖得掉"尽调，**没有发现任何一条"卖不出去/量级卖不动/钱包被 hook"的证据**，校准探针有效（把 207 个已知坏币全部识别）；但因"策略钱包按真实持仓量的实际成交"在链下**结构上无法证成**，形式裁定为 **`UNRESOLVED_EXIT_SAFETY`**——即"没被证伪能卖，但也不能盖章保证能卖，最后一层只能靠极小额真钱封口"。`GO=NOT_MADE`。

## 1. 勘误重跑

首版实现只从 GL5v3 `exact_size_quote` 取历史仓位量，把 104 条真卖(REAL_SELL)腿误判为 qty 缺失。按已冻结的 `GL7v2_preregistration_erratum_qty_lineage`（SHA `735f08a70e63b3f052c2a7556b77e51ff3c6114cf909a1c2a8146407edf4b70a`）修正：qty 先取 GL5v3 exact quote，缺时回退同 pool/offset 的 GL5v2 冻结 `position_qty_raw`，都无才 unresolved。360 腿的 qty 来源：**253 v3 exact / 104 v2 回退 / 3 真缺**，与勘误诊断一致。预注册本体 SHA 未改（`a23bd56…76b21c`）。

## 2. 四条证据线结果

### 线 A — 我方钱包历史真卖（最强真值）
- 51 笔真实卖出尝试，成功 3，**48 笔失败全部为 `POOL_COLLAPSE`**（失败块的池内 WETH 储备比≈0.008，即只剩约 0.8%），`UNRESOLVED_FAILURE=0`、`confirmed_wallet_restriction=0`。
- **结论**：我们真金卖不掉的直接原因是**池子被撤流动性/rug（激进版吃进的那批）**，不是代币对我方钱包设了 hook/黑名单。这把"钱包级毁灭风险"从"未知"降为"历史证据里 0 例钱包级阻断"。

### 线 B — 按真实历史仓位量的只读卖出模拟（量级缺口）
- historical_qty：evaluable≈348、**failure=0**、deterioration>10pp=0、中位滑点≈ −3e-6（可忽略，甚至略优）；two_x（2×真实量）同样 **failure=0**、deterioration>10pp=0。
- baseline($50)：evaluable≈353、failure=0。
- `material_size_risk=False`，线 B **pass**。
- **结论**：放大到真实仓位量乃至 2×，模拟卖出仍能成交、回收率 ~98–99%（扣手续费/haircut），**无量级卖不动迹象**。

### 线 C — 转账可行性（"买得进卖不出"检测）
- new_address 差分 eth_call：evaluable≈353、**restriction_n=0**（无"买成功、卖失败"蜜罐特征）。
- historical_holder / strategy_wallet_exact：`evaluable=0`，`UNRESOLVED`（eth_call 无法验证到账、策略钱包从未持有这些反事实代币）——**这是结构性无法补的缺口，如实标 unresolved，不冒充证据**。
- `material_transfer_risk=False`，线 C 形式 pass=False（因上面结构性 unresolved）。

### 线 D — 校准（反自欺）
- 对 207 个已知坏币跑同一套探针：**207/207 全部识别为不可卖/坍塌**（199 靠储备坍塌 + 8 靠 atomic 限制探测），evaluable_rate=1.0，Wilson 95% 下界=**0.982**，`method_valid=True`。
- **结论**：探针不是瞎盖章——它确实抓得住坏的，因此线 B/C 对保守集的"干净"是有意义的。

## 3. 裁定

| 维度 | 结果 |
|---|---|
| A 历史真卖 | 48 失败全 = 池坍塌；钱包级阻断 0 例 → **未发现钱包级风险** |
| B 量级 | 真实量/2× failure=0，无滑点崩溃 → **未发现量级风险** |
| C hook | new_address restriction=0；holder/钱包精确态结构性 unresolved |
| D 校准 | 207/207 命中，method_valid → **探针有效** |

**综合 `UNRESOLVED_EXIT_SAFETY`**：四条线里能查的都没查到"卖不出去"，探针也证明有效；但线 C 的"策略钱包按真实持仓量的真实成交"链下无法证成，故不能升级为 `RESIDUAL_RISK_LOW`。这既不是坏消息（没发现毁灭性证据）也不能当放行（残余只能真钱封口）。

## 4. 边界（必须重申）
- 只读 `eth_call`/atomic 模拟不含真实抢跑、MEV、竞争与签名广播；能**发现**卖不掉的迹象，不能**保证**真钱必然成交。
- 线 A 的真卖来自**激进版实盘**在**已 rug 的币**上，不能直接外推到保守版会遇到的币；但它证明了"我们观察到的失败机制 = 池坍塌，而非钱包 hook"。
- 全程只读：仅 `eth_call`，无 public 回退、无 send/sign/broadcast、无 Redis/signals/executor/live 改动，输出无 endpoint 泄漏。回归 8/8。
