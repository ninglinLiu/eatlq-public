## 1. 已核实的事实基线（不要重新发现）

### 1.1 机制（官方，已核实）

来源：`https://docs.morpho.org/learn/concepts/irm`  
技术页：`https://docs.morpho.org/get-started/resources/contracts/irm`  
常量实现：`https://github.com/morpho-org/morpho-blue-irm/blob/main/src/adaptive-curve-irm/libraries/ConstantsLib.sol`

AdaptiveCurveIRM 有两层，必须在分析里分开，不许揉成“利率变了”：

**A. 曲线（瞬时，交互时发生）**

- `u_target = 0.9`
- `CURVE_STEEPNESS = 4`
- 利用率从 90% 跳到 100%，借款利率瞬时约变为 4 倍（相对当时的 `r_90%`）
- 利用率从 90% 掉到 0%，瞬时约变为 1/4

**B. 自适应（连续，即使无人交互也在走）**

- 利用率持续高于目标，`r_90%` 上移；低于则下移
- 离目标越远，移得越快
- 官方例子：利用率 100% 维持 5 天，`r_90%` 大约翻倍（最大速度）；45% 维持 10 天大约减半；95% 维持 10 天大约翻倍
- `r_90%` 有上下界（约 0.1%/年 到 200%/年）

**APY 定义**（必须用，不许用简单 APR 冒充 APY）：

```
borrowAPY = exp(borrowRate * 31536000) - 1
supplyAPY = borrowAPY * utilization * (1 - fee)
```

2026-08-15 核心市场快照（官方 GraphQL，R0 必须重核）：

- 利用率 0.8682，**在目标下方约 3.2 个百分点**
- 供给 APY 4.12%，借款 APY 4.76%
- 供给 $1.48B，借款 $1.28B

USDe/USDC 当日利用率 0.9010，几乎钉在目标上。WETH/USDC 0.8710，与核心市场相近。这三个数决定了本轮的零假设：**核心市场大部分时间贴着目标下方爬，而不是在 0 和 1 之间大幅摆动。** 若你的面板显示它经常冲到 99% 或掉到 50%，先查仪器，再谈发现。

### 1.2 本轮要回答的唯一科学问题

> 在 `cbBTC/USDC` 86% 市场上，利用率对 90% 目标的偏离，是否会按 AdaptiveCurveIRM 的两层机制转化为**可预登记、样本外仍在、且对 $1,000 有经济意义**的利率路径？还是：机制成立，但路径已被市场参与者抹平，只剩 4% 底？

这不是“做 LP 好不好”，也不是“方向能不能做”。这是一个带闭式机制的均值回复 / 状态依赖问题。最可能的结果是证伪经济意义。

### 1.3 明确不是本轮的问题

- 清算奖金、清算延迟、清算人竞争
- 预言机 vs 现货（那是 R2）

- 与 F03 正交（那是 R4）
- vault 策展人再配置的完整归因（可作描述性附录，不得当主结论）
- “如果我们能在利用率 95% 时借入再在 85% 时存入”这类需要真实 borow/supply 的故事 —— 本轮只允许纸面、只读

### 预登记（写进 `out/r1_preregister.json`，在看任何相关图之前）

必须预先写死，写完再画图：

```
train_end          = 面板 70% 分位时间（含）
holdout_start      = 其后第一根
primary_market     = cbBTC/USDC 86%
kink               = 0.90
band_inner         = 0.88–0.92        # “贴着目标”
band_high          = utilization >= 0.95
band_low           = utilization <= 0.80
horizon_hours      = [1, 4, 12, 24, 72]   # 日频面板则改成 [1, 3, 7] 天，并改名
min_abs_du         = 0.01             # 小于 1 个点的利用率变化当噪声
cost_proxy_bps     = 你必须单独论证：存取 USDC 的 gas + 若经 DEX 进出的滑点
                      默认先给三档：10 / 30 / 80 bps 往返，不许只报 0 成本
capacity_notional  = 1000 USD
capacity_violation = share > 0.01 → 剔除（对这个市场应永远是 0）
```

**零假设 H0（主）：** 在 holdout 上，从 `band_high` 出发，未来 24h（或日频 3 天）利用率的中位变化不小于 0（不会系统性回到目标）。机制若只在训练窗好看，算失败。

**备择（机制成立的最小形式）：** holdout 上，`band_high` 之后利用率中位下降，且与 `band_inner` 对照的差异在预登记检验下显著；**并且**对应的供给 APY 路径在扣 30 bps 往返后，对 $1,000 的 24h 超额期望 ≤ 0。  
注意：机制成立与“能赚钱”是两句分开的话。我要你两句都判。

**H0b（自适应 vs 曲线）：** 在没有新的 Supply/Borrow/Withdraw/Repay 事件的间隔里，利率仍按自适应公式移动。没有事件数据则标 INCONCLUSIVE，不许用 API 小时点冒充“无交互间隔”。

### P1 — 描述性基准率（必须先做）

对核心市场报告分布，不要只报均值：

- 利用率：p01/p10/p50/p90/p99，在 `band_inner` / `band_high` / `band_low` 的时间占比
- `r_90%` 或借款 APY：同上
- 利用率一阶差分、利率一阶差分
- 利用率与利率的同期相关、交叉相关（±12 小时或 ±3 天）
- 连续停留在 `band_high` 的时长分布

对照官方机制做**定性一致性检查**（不是假设检验）：

- 利用率上穿 90% 的同时，利率是否瞬时变陡（曲线层）
- 若持续留在 95%+，利率是否在随后数日抬升（自适应层）
- 若这两条在描述层就反着来，先怀疑仪器（APY 定义、应计、时间戳对齐），再谈“市场打破了 IRM”

USDe、WETH 两市场只出同样的表，放附录。主文不许把三市场平均。

### P2 — 预登记检验

只在 holdout 上报告主裁决。训练窗可以用来确认代码没写错，但训练窗数字不得出现在“结论”段落。

对每个预登记 horizon：

1. 事件定义：利用率从 `band_inner` 进入 `band_high` 的时刻为 t0（第一次进入，不重叠：上一个事件结束前不重新开仓）。日频则用日收盘。
2. 结果：`u(t0+h) - u(t0)`，`borrowAPY(t0+h) - borrowAPY(t0)`，`supplyAPY(t0+h) - supplyAPY(t0)`
3. 对照：同一时刻仍在 `band_inner` 的随机（或全部）对照小时/日，数量匹配
4. 检验：预登记一种，写死。建议：对差分做 Wilcoxon 符号秩或对两组做 Mann-Whitney，双侧，α=0.01。不要事后换检验。
5. 多重比较：5 个 horizon 要校正（Holm 或 Bonferroni），主裁决看 24h（或 3 天）这一个，其余当描述

**经济层（必须）：**

假设一种**纸面、只读、不执行**的供给择时：在 t0 进入 `band_high` 时“视为存入” $1,000 USDC，在 t0+h 或回到 `band_inner` 时“视为取出”。收益 = 期间供给利息 − 预登记成本档。

必须逐项列：

- 毛利息（用面板供给 APY 积分，写明积分规则）
- gas 往返（给 Base 当日量级的来源，或写假设并做 3 档敏感度）
- 若进出需要换出 cbBTC/其它资产：本策略假设口袋里已有 USDC，**不许偷偷加一层 DEX 好运**
- `implied_share_p50 / p99 / capacity_violation_pct`

主结论用 30 bps 档。10 bps 与 80 bps 放敏感度。任何年化 > 20% 的数，我先当积分错误或样本只有几个 t0。

### P3 — 机制分解（若 P2 的描述层看起来像机制）

把利率变化拆成：

```
ΔborrowRate ≈ 曲线项(Δu | r_90%) + 自适应项(Δr_90% | u)
```

曲线项用官方 `curve(u)` 在 `r_90%` 冻结时的闭式差。自适应项用官方 `speed` / `k_p=50`。  
若你没有 `rateAtTarget` 序列：

- 优先从 IRM `BorrowRateUpdate` 事件取
- 否则从 `borrowRate` 与 `u` 反推 `r_90% = borrowRate / curve(u)`，并写明这是反推

分解失败（残差系统性大于两项）→ 写仪器或 API 定义问题，不要写“我们发现了第三种 alpha”。

### P4 — 失败模式清单（必须逐条回答）

1. API 小时点是快照还是区间平均？你怎么知道？
2. 应计未校正会不会制造假的利率锯齿？
3. 利用率接近 90% 时，1% 的噪声是否被你当成“进入 band_high”？
4. 事件重叠、同一压力日重复计数了吗？
5. holdout 是否刚好是一段单边 BTC 行情？若只有一个宏观制度，写 UNDERPOWERED
6. $1,000 的利息在 24h、4.5% APY 下约 $0.12。任何成本超过这个数都会吞掉择时。你有没有把这句写进主结论？

## 8. 一句话
