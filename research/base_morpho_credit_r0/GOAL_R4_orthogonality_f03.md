### 1.2 本轮唯一科学问题

> 把核心市场的信贷状态（利用率/利率、预言机基差、危险带进入）对齐到 F03 信号时，这些状态是否提供 **F03 分数线性解释不了的** 增量信息？增量若存在，它是方向、是回避（否决器）、还是只对不可成交的 tick 残差有效？

零假设：**信贷特征在 holdout 上对 F03 残差的增量解释为 0；作为否决器也不能降低预登记的不利路径率而不杀死全部信号。**

### 1.3 正交的操作定义（预登记，不许事后改）

同时报告三种，主裁决看 A：

**A. 残差增量（主）**  
在训练窗用 F03 分数（及报告里已有的同期收益符号，如果他们已经当特征用了）拟合 holdout 上的 1h tick 收益。再加入信贷特征，看 holdout 上 RMSE / 线性 R² 的增量。预登记：增量 R² < 0.01 视为 0。

**B. 否决器（次）**  
预登记一条规则，例如：“利用率 ∈ band_high 或 |basis| > 30 bps 或 24h 内核心市场进入 deep_danger 的借款 USD 高于训练窗 90 分位时，忽略 F03”。看 holdout 上：信号数、毛利差、不利路径率。否决器必须在训练窗定阈值。

**C. 时间重叠诊断（描述）**  
F03 信号是否集中在信贷压力小时？若是，F03 可能只是同一宏观冲击的现货面，不是独立机制。

不许用机器学习堆特征。最多线性模型 + 一条预登记否决器。上 XGBoost 我会当逃避。

### P1 — 对齐诊断（先于模型）

- 覆盖率、每个月的 n
- 信贷特征缺失是否与 F03 活跃相关（相关则是选择偏差）

若 F03 信号几乎全落在同一两个宏观日，写 UNDERPOWERED。

### P2 — 残差增量（主检验）

训练窗：

```
y = 1h_tick_return
m0: y ~ f03_score
m1: y ~ f03_score + credit_features
```

只报 holdout：R²、RMSE、增量、每个信贷系数的符号与稳健性（预登记：对系数做 bootstrap 或简单 t，α=0.01，Holm 校正）。

**泄露检查（必须）：** 同期（lag=0）模型放附录。若只有同期有增量、lag=1 没有，主裁决按零处理，并写“同期相关，不是可交易正交”。

**动量伪装检查：** 若 F03 分数已含收益符号，信贷增量必须在控制了 `sign(current_return)` 之后仍在。不在，则信贷只是又一个动量面。

### P3 — 否决器（次检验）

训练窗定阈值，holdout 上：

| 集合 | n | 毛利差 bps | 不利路径率 | 扣 120 bps 后中位 |
|---|---|---|---|---|
| 全部 F03 | | | | |
| 否决后存活 | | | | |
| 被否决 | | | | |

否决器若把 n 降到 < 30，UNDERPOWERED。  
否决器若只杀掉亏损单也杀掉同样比例的盈利单，REFUTED。  
否决器不得在 holdout 上改阈值。

### P4 — 经济诚实

- 任何“正交 alpha 年化”不得出现
- 最多说：在 tick 空间里是否有增量；可成交性仍未验证
- $1,000 容量：信贷市场侧份额可忽略，现货侧仍未验证。写 `USD_CAPACITY = UNVERIFIED`
