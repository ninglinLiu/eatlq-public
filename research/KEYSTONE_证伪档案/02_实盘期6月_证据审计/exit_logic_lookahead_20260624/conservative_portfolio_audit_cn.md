## 2. 「复利」到底是什么意思？

上一轮报告里的「+47%/月」容易误导。三种口径：

| 口径 | 含义 | 你的 $500 钱包下结果 |
|---|---|---|
| **不复利（本报告推荐看）** | 永远只拿 $500 当本金，每笔固定 $50，利润提出 | **$1,122/月** |
| **软复利 10%** | 每笔 stake = min($50, 账户×10%) | **与不复利相同** — 因为 $500×10%=$50，已顶 cap |
| **硬复利** | 利润滚回账户，下一笔按更大 equity 算 | **仍相同** — stake 被 $50 cap 卡住 |

**结论**：在 **$500 钱包 + $50 单笔 cap** 下，**不存在有效复利**——要看到复利效果，必须 **钱包涨到 >$500**（10%>$50）或 **提高单笔 cap**。之前说的「复利月化 47%」= `$1,122 / $500`，只是把 **绝对美元利润换算成钱包百分比**，不是「利滚利把仓位滚大」。

## 3. 动态仓位：另一 Agent 为什么说「非常不安全」？

Live 动态仓（`DYNAMIC_SIZING=1`）逻辑：在 **进场前** 链上状态，找 **能通过 friction 的最大 notional**，受限于：
- 账户 cap（`MAX_POSITION_ETH`）
- 池深 5%（`MAX_POOL_SHARE`）
- 成交量份额

### 回测对比（同一批 live_full 池，walk-forward 外）

| 模式 | 月化 $ | 平均单笔 | 最大单笔 | 峰值同时占用 | 评价 |
|---|---:|---:|---:|---:|---|
| **固定 $50 + 并发3 + $150上限** | $1,122 | $50 | $50 | **$150** | ✅ 当前 live |
| **安全动态**（阶梯≤$50 + 同上限制） | $1,122 | $50 | $50 | $150 | = 固定仓（cap 卡住） |
| **unsafe 动态**（阶梯 $1000/$300/$100 + 无组合上限） | **$6,351** | **$421** | **$1,000** | **$3,000** | ❌ 另一 Agent 警告的就是这个 |

**unsafe 为何危险**：$500 钱包却可能 **峰值占用 $3,000**（6× 钱包），单笔最坏 **−$1,000**（深池快撤）。月化数字好看，但 **左尾被放大一个数量级**。

### 想「动态 + 复利」又控风险？合理折中（建议，未上线）

```
单笔 stake = min(
    $50,                          # 账户硬顶（你现在）
    钱包 × 10%,                   # 软复利（钱包>$500 才开始生效）
    池 WETH × 5% × ETH价,         # 深度顶（蝴蝶效应 guard）
    (钱包 × 35% − 已占用) / 空槽   # 组合层上限（比逐仓多一层）
)
并发 ≤ 3
```

- **钱包 $500 时**：与固定 $50 **完全相同**。
- **钱包滚到 $1,000**：单笔可到 $50 cap… 仍 cap；要到 **$800+** 软复利才 >$50，但你 cap 在 $50 就不变。
- **若将来提高 cap 到 $100**：必须 **同时** 保留 5% 池深 + 35% 组合上限 + 并发 3，否则就是 unsafe 那条路。

**判定**：在你当前 **$50 cap** 下，**开启动态 sizing 没有额外收益**（回测 identical）；风险来自 **把 cap 调到 $300–$1000 且去掉组合上限**。

## 5. QV2 vs Fork：哪个更真实？

### 短答

| 问题 | 答案 |
|---|---|
| **哪个更真实？** | **Fork 真买真卖（real-gas）更真实** — 它测的是「链上能不能真 swap + gas」。 |
| **你当前 live 配置下两者差多少？** | **几乎没差** — live_full 通过的 119 池，QV2 与 fork **100% 一致**（2 笔 fatal 相同，delta=0）。 |
| **什么时候 QV2 会撒谎？** | **honeypot / gas bomb / 能买不能卖** — QV2 报价 OK 但 fork revert。历史 n=131 外部过滤 **删 0 笔**（那批样本里没命中），但 **6/23 live PARADAENGI 就是 live 实锤**。 |

### 长一点

- **QuoterV2**：`eth_call` 模拟 swap 报价，**快、便宜**，但与 live 前置检查 **同源**，共享 **「看不见真 revert」** 的盲区。
- **Fork real-gas**：archive 节点上 **真发 swap + 真 gas cap**，地面真值；stress167 / 167 rug 赢家 **必须用它**。
- **live_config 双尺子对账**（6/24）：在 **live 通过且可交易** 子集，QV2 与 fork **组合指标几乎相同** — 因为这批里 **没有 rug 漏网**，fatal 来自 **clean 价格暴跌**，两种尺子都能看见。
- **结论分层**：
  1. **评估「已知安全子集」利润** → QV2 够用（与你现在 F 黑名单策略一致）。
  2. **评估「毁灭率 / 左尾 / honeypot」** → **必须 fork**；QV2 **系统性低估** 左尾。
  3. **评估「反应型撤池 / 出场延迟」** → 两种都不够，要 stress167 那套 **延迟 + real-gas exit_p\***。
