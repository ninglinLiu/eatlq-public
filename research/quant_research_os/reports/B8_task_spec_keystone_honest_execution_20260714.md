# B8 · 任务书:KEYSTONE 诚实可执行口径重验(目的是找真钱,不是找借口掐死)

## 0. 为什么重做(纠正上一轮的方向性错误)

B5 用"缺第三方成交证据 = −100% 全损",把 43 个执行缺口一刀切成致命亏损 → pooled −4.61% FAIL。B7 复核证明这是**过度保守的冤杀**:43 个缺口里 **41 个在出场块原子实测可卖**;换成诚实口径 pooled +57.67%、致命率从 37.9% 掉到 3.45%、W2 从 −18.48% 翻 +58.68%。

**但 +57.67% 也不能信**(事后定义 + 助手地址原子 + QuoterV2 报价 + 假设即时出场)。本任务的目的:**用一个既不冤杀、也不注水的预注册口径,测 KEYSTONE 到底有没有可执行的正 EV。**

## 1. 判据总原则(写进审查)

- **目的是挣钱,证伪是质量筛子。** 同时防两头:防注水(过度乐观),防冤杀(用技术性缺失当全损)。
- **adverse/−100% 只在"真无从得知"时用**:只要能拿到真实链上证据(真成交 或 原子可卖),必须用证据,禁止用全损偷懒。
- 真的 rug(原子 revert 且此后无任何真实卖出成交)才算 −100%。

## 2. 诚实出场口径(预注册,冻结后不许因结果改)

对每笔入场后的出场,按**证据优先级**取价,逐笔记录用了哪一档:
1. **真实成交(首选)**:signal/trigger 后、在**可达延迟预算**内(预注册 L∈{即时、30min、60min} 三档都跑,主口径取现实值如 30min),我方向上第一笔**真实挖到的成交价**。
2. **原子可卖回退**:若延迟窗内无真实成交,但出场块**原子往返卖成功**,按原子实收价成交,并**扣一个预注册滑点/容量折扣**(不许用零滑点 QuoterV2 报价当真实成交)。**同时标注 helper-address 风险**:原子买家是助手地址,需抽样核对是否存在地址特异性 honeypot(真持仓地址能否卖)。
3. **真 rug**:原子 revert 且此后无任何真实卖出 → −100% + gas。

**三档延迟(L)都必须出结果**,展示 EV 随出场延迟的衰减曲线——这是本策略的生死线。

## 3. 入场与成本

- 入场:signal_time 后固定延迟的**下一笔真实成交价**(不用报价/中价)。
- 成本:B3 冻结模型(真 gas、含费含冲击、$0.075/腿)。
- 容量:0.001 WETH 主口径;另报**更大名义额**下 QuoterV2 冲击,说明真实容量上限。

## 4. 验证框架(防过拟合 + 防事后)

- **重新预注册本 estimand**(冻结哈希),不得沿用 B7 事后混合口径当 PASS。
- **跨 regime + 滚动子窗**(别压 W1/W2/W3 三段);**OOS/forward-shadow**:早段定任何阈值,后段只验。
- **regime 门重测**:B6 的 20% 冻结阈值失配(真风险代理最低 48.65%,永不开工=假 FAIL)。改为**从 in-sample 风险代理分布派生阈值**(如按分位),OOS 验证;并**先测不装门的诚实版是否本身就正**(B7 迹象显示 W1+W2 诚实口径均正,门未必必要)——若不装门已达标,门只作增益测试。

## 5. 预注册右尾判据(冻结)

诚实版(主延迟档)**通过**需同时:pooled mean>0 且 top1 移除后>0;每 powered(n≥20)子窗不破 −10% floor;≥2 powered regime 正 mean+正 alpha;MC 终值 p5>100R、MDD p95≤20R;**OOS 段同为正**;**且在现实延迟档(非即时)下仍成立**。任一不过→FAIL(这次的 FAIL 必须是"诚实口径下真不行",不是缺数据冤杀)。n<20 只描述。

## 6. 必须产出
